# 🤖 AI-Powered Chatbot Application

This repository contains the source code and learning materials for building an **AI-powered chatbot application** from scratch. The project walks through core concepts such as chatbot basics, AI API integration, prompt design, conversation memory, and creating a web interface using **LangChain** and **Gradio**.

---

## 📌 What You Will Build

By the end of this project, you will have:

* A working AI chatbot that can hold conversations
* An understanding of how AI-powered apps work
* A chatbot with a defined personality
* Persistent chat history
* A simple and interactive web interface

---

### 1. Introduction & Foundations

## 🚀 Getting Started

1. **Clone the repository**

   ```bash
   git clone <your-repo-url>
   cd <your-repo-name>
   ```

2. **Install dependencies**

   ```bash
   pip install -r requirements.txt
   ```

3. **Set up environment variables**

   ```bash
   export OPENAI_API_KEY="your_api_key_here"
   ```

4. **Run the application**

   ```bash
   python app.py
   ```
